# Fatemeh Chegini — HugoBricks portfolio overlay

This package is designed to replace the corresponding files in your existing local `hugobricks` repository.

## Install
1. Keep your original HugoBricks repository as a backup.
2. Copy the contents of this package into your existing `hugobricks` folder, preserving folders and replacing files when asked.
3. From the HugoBricks root run:
   `hugo server`
4. Open `http://localhost:1313/`.

The package intentionally does NOT include the large `themes/`, `.git/`, `public/`, or `resources/` folders. Your existing local repository already has them.

## Before publishing
- Add a professional profile photo if desired.
- Add the final PDF CV to `static/uploads/` and replace the placeholder sentence on `/cv/` with a download link.
- Add LinkedIn, GitHub, Google Scholar, ORCID links once you choose the public URLs.
- Review publications and any work-in-progress wording before making the repository public.

## Deploy
The configured base URL is `https://chegini.github.io/`. Deployment to GitHub Pages can be added after the local site looks the way you want.
